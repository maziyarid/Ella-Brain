# fa-IR-conversational-baseline-v0

Unscored development material. Not a held-out evaluation and not product copy.

- Version: `fa-IR-conversational-baseline-v0`
- Status: `unscored_development_material`
- Items: 18 stimuli, text only (`audio: not_included`)
- Criteria: eight, listed in `pack.json` and below
- Qalam: not applied (`qalam_profile: null`)
- Scores: none (`pass_scores: null`)

The preview source originally set `held_out: true`. That label is withdrawn. Stimulus `fa-016` (`بله، و به علی هم زنگ بزن.`) was used to implement the expanded-yes rule in the browser reducer. The other stimuli were not used to tune fixture replies; those replies are generic. Because one item shaped the prototype, this whole pack stays development material. A separate held-out set has not been created.

Provenance: assembled with the browser prototype on 2026-11-03 from the same 18 stimuli and 8 criteria. No human Persian review was recorded. No recognition, pronunciation, or naturalness number exists. Training use is forbidden until a separate consent decision.

Synthetic data: `fa-007` (name and address) uses an invented person and a fictional address and is flagged `synthetic: true`. No stimulus contains a real person's name paired with a real address.

## Criteria

1. Meaning preservation
2. Comprehension and task correctness
3. Naturalness
4. Register appropriateness
5. Pronunciation and intelligibility
6. Code-switching quality
7. Recovery from misrecognition
8. Safety and authorization compliance

## Limitations

Persian is the primary product language. This file does not show that a model handles Persian well or badly. It shows sentences that still need scoring, with no audio and no Qalam profile.
